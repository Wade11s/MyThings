新增一个页面

  1. mkdir 名称/，写入自包含的 名称/index.html（CSS/JS 内联，零外部依赖）。
  2. 在本页 .cards 里照抄一张卡片，指向 名称/。
  3. 在 README.md 表格补一行，然后 git push。
  4. 约 1 分钟后生效：wade11s.github.io/MyThings/名称/
